## 1. 背景・問題設定

概念史・系譜学・制度史など、**時代をまたいで規範や実践をつなぐ論文**では、「正しさ」が実証論文の正しさ（測定・追試）と違う。既存スキルは次を担うが、通時的論文の上流（選定と主張の型）は空いている。

| 既存スキル | 担うこと | 通時的論文で足りないこと |
| :--- | :--- | :--- |
| `literature-search` | OpenAlex 等の論文API、対立陣営、マトリクス | 古典校訂本・J-STAGE/CiNii・一次文献の版キー。断面の**選び方** |
| `source-criticism-gate` | Web 情報源の Tier 1–3 | 一次／二次、校訂本／通史、伝播／類似の区別 |
| `claim-evidence-gate` | 執筆後の7軸監査 | 執筆**前**の主張型。伝播・連続・新規性・アナクロニズム |
| `fact-grounding-rule` | `papers/` 実体化なしに引用しない | 実体化しても、接続の種類（伝播か並置か）は監査しない |

**よくある誤解**: 系譜学は通史である。選んだ断面をつなげば「成り立ち」が証明できる。  
**本スキルの立場**: 本リポジトリが採用する系譜学は、**通史ではなく断面の選択的接続**である（Foucault 系の系譜は網羅を要求しない）。ただし選択である以上、(a) 基準を書く、(b) 選ばない対抗系譜を名指す、(c) 接続の種類を型付けする、の三つが要る。これを怠ると、類似を因果に、古典二点を「近世までの連続」に、分析概念を過去の行為者の学説に読み替える。

**既知の落とし穴（jiatama-supremacism より）**:

| 落とし穴 | 結果 |
| :--- | :--- |
| 有料通史（Yates 1966, Blair 2010 書籍）に依存 | 買わない方針と衝突。古典一次文献へ代替すべきだった |
| 類似を翻案・伝播と書く | T-3 で経路証拠なし。並置へ格下げ |
| 「現代は速度と必須性が質的に新しい」 | 歴史家本人が連続と必須性の先例を書いていた（Blair p. 12, Naudé）。T-4 で不成立 |
| 四断面を選んだ理由を書かない | 第2章レビューがチェリーピッキングを未列挙反論として指摘 |
| カント／記憶術を造語概念と同一視 | アナクロニズム。節メモで禁止しても、章末の「いずれも引力」で戻る |
| OpenAlex だけ | 「地頭力」が中世の地頭に誤爆。日本語制度史は J-STAGE が本体 |

## 2. スキル目的

通時的論文において、**主張を型付けしてから**文献を選び、断面を設計し、接続文を書く。型が証拠に見合わないときは、主張を縮小する（書かない／並置／程度差／矛盾の可視化）。網羅的通史を書くスキルではない。

---

## 3. 発動タイミング

- 研究計画が概念史・系譜学・思想史・制度史・受容史・「成立の経緯」を含むと判明した時
- 文献調査の前に、古典・一次史料・日本語紀要が OpenAlex の外にありそうな時
- 章・節で時代をまたぐ接続文（「〜から」「翻案」「連続」「現代に固有」）を書く前
- 外部レビューまたは自己監査が、チェリーピッキング・アナクロニズム・伝播の証拠不足を指摘した時

非発動: 単一年次の実証、横断的サーベイで時代接続を主張しない論文。その場合は既存の `literature-search` と `claim-evidence-gate` で足りる。

---

## 4. 主張の型（中核）

各通時的主張に、次のいずれか**一つ**を付ける。複合なら文を分割する。

| 型 | 主張していること | 必要な証拠 | 典型的失敗 | フォールバック |
| :--- | :--- | :--- | :--- | :--- |
| **T0 本文存在** | テクスト L に文 X がある | 校訂本のキー（Stephanus, AA, 巻節）＋ `papers/` の検証済み抜粋 | 訳書頁の捏造、未読二次の外挿 | 引用しない |
| **T1 解釈** | X は Y と読める | T0 ＋代替読みの承認 | 一意の意味に固定 | 「読みうる断面」に弱める |
| **T2 制度** | 実践が制度・教育の一部門だった | 一次の規程・教科書・事例 | 一校事例を全国化 | 事例命題に限定 |
| **T3 伝播** | A が B として受容／翻訳／導入された | 翻訳・カリキュラム・引用経路 | 類似＝因果 | **並置・比較** |
| **T4 連続** | 方法や規範が期間 P まで続いた | 連続を論じる一次または複数時点の一次 | 古典二点で「近世まで」 | 断面のみ。通時連続は書かない |
| **T5 新規性** | 時期 P の条件は種類として新しい | 敵対的還元（量／時間、程度差）に耐えること | 歴史家が先に連続を書いている | 程度差、または規範と実践の矛盾の可視化 |
| **T6 非同一視** | 過去の行為者が本稿の造語概念を保持していた、とは**言わない** | 明示的な自己同一視がある場合のみ例外 | カント＝地頭至上主義 | 「本稿の分析概念で読む」 |

`claim-evidence-gate` の Philological Precision / Context Safety は T0–T1 の事後監査に対応する。T3–T6 は本スキルが上流で処理する。

## 5. ワークフロー（8 Step）

### Step 0: 論文型の判定

`research-plan.md` の方法論を読む。次のいずれかがあれば本スキルを継続する。

- 概念史、系譜学、思想史、制度史、受容史
- 章立てが成立→制度化→変容など通時弧
- 古典・校訂本・法令・試験制度を一次とする計画

該当しなければ終了し、既存スキルへ戻る。

### Step 1: 主張インベントリ（文献検索の前）

`docs/<paper-id>/design/sot/diachronic-claim-inventory.md` を作り、章・節ごとに「書きたい接続」を T0–T6 で仮置きする。証拠が空の型は、検索クエリになる。

### Step 2: 断面の選択基準と対抗系譜

断面を列挙する前に、次をインベントリへ1段落で書く。

1. **選択基準**（正典性、制度への埋め込み、本稿の造語概念との語彙的近さ、OA 一次が取れること、等。使う基準を明示）
2. **対抗系譜を1つ名指す**（選ばない理由。例: 科挙は主系譜ではない）
3. **「成立」の意味**（網羅的起源ではなく、反復して観測できる起点の特定、等）

系譜学は選択的である。禁止するのは、選択を通史として読ませることである。

### Step 3: 一次の層を二次より先に置く

1. 通史・概説（Yates 型）は Discovery に留め、引用根拠にしない。
2. 通史が依拠する古典・法令・一次論文へ降りる。版キーを stub の引用キーにする。
3. 有料単著は買わない（論文リポジトリの方針に合わせる）。同じ T 型を担える OA 一次へ替える。代替不能なら当該 T 型の主張を縮小するか、節を書かない。
4. 日本語制度史は OpenAlex だけで終わらせない。J-STAGE / 機関リポジトリ / CiNii を検索対象に含める。

`literature-search` の API ステップの**前または並行**で本 Step を行う。プロバイダー外チャネルは WebFetch と manual-stub で接地する（v1.0 で新APIは足さない）。

### Step 4: 伝播テスト（T3）

「翻案」「由来」「輸入」「影響」を書く前に、次のどれかがあるか確認する。

- 翻訳・紹介の書誌
- 制度導入の一次（学則、試験規程、教科書）
- 後続テクストが先行テクストを名指し引用していること

無ければ T3 を T 並置（比較）に落とす。`literature-gap-analysis` の新規性が「系譜の接続」なら、同時に「並置・比較」へ直す。

### Step 5: 連続・新規性の敵対的還元（T4 / T5）

「現代に固有」「質的に新しい」「〜まで続いた」を書く前に、依拠する歴史家本人が連続や先例を書いていないか読む。敵対的還元の定型:

- 速度は量を時間で割ったものではないか
- 必須性は依存の程度差ではないか
- 古典の二点は通時連続を実証しないのではないか

耐えない場合は、T-4 型フォールバック（程度差、矛盾の可視化、断面に留める）をインベントリに書く。**章の執筆開始条件**にする。

### Step 6: 語のずれ（断面間）

同じ分析語（例: 「内部」「記憶」「能力」）が、断面ごとに指示対象を変えていないか。変わっているなら、章冒頭または接続部で「本稿が一つの規範として束ねる分析的構成物である」と書く。`scholarly-concept-modeling` の定義と矛盾させない。

### Step 7: 受容と解釈を分けて書く

「受容されてきた」は T3 に近い経験主張である。誰がどう受容したかの一次が無ければ、「読みうる」「本稿が起点として用いる」に弱める（T1）。

### Step 8: 章起稿前チェック

節の本文を書き始める前にインベントリを更新する。

- [ ] その節の屋台骨主張に T 型が付いている
- [ ] T0 は stub の抜粋範囲内
- [ ] T3/T4/T5 はテストを通過したか、フォールバック済み
- [ ] T6（歴史的行為者＝造語概念）を主張していない
- [ ] 選択基準と対抗系譜がインベントリにある

通過後に `counter-argument-tdd` の節レベル反論へ進む。
