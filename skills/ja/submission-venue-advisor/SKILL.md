# 提出先選定・投稿ガイドスキル (Submission Venue Advisor)

## 目的
完成した論文を公開・提出する際、研究分野・執筆言語・公開目的（先行性確保・査読フィードバック獲得・アウトリーチ）に基づき、最適なプレプリントサーバーやオープンアクセスリポジトリを提案し、提出前の品質チェックから投稿手順までを案内する。

## 発動タイミング
- 論文の初稿が完成し、公開先を検討する時
- プレプリント公開（先行性の確保・査読前フィードバック）を検討する時
- 学位論文・ワーキングペーパーのリポジトリ登録時

## 主要な提出先の分類マトリクス

### 汎用（全分野対応）

| サーバー | 特徴 | 言語 | 費用 |
|---|---|---|---|
| **Zenodo** | CERN 運営。全分野・全ファイル形式対応。DOI 自動付与。GitHub 連携可 | 多言語可 | 無料 |
| **OSF (Open Science Framework)** | プロジェクト管理機能付き。データ・コードとの一体化に強い | 多言語可 | 無料 |
| **Research Square** | 学際的。査読付きプレプリント機能あり | 主に英語 | 無料 |

### 分野別プレプリントサーバー

| 分野 | 推奨サーバー | 備考 |
|---|---|---|
| 経済学・社会科学・法学 | **SSRN** (Elsevier) | ワーキングペーパー文化が強い。政策研究との相性が良い |
| 物理学・数学・CS・統計・計量経済 | **arXiv** | 最も歴史が長く影響力大。econ カテゴリもあり |
| 生命科学 | **bioRxiv** | 生物学系の標準 |
| 医学・健康科学 | **medRxiv** | 臨床系。免責表示が必須 |
| 心理学 | **PsyArXiv** | OSF 系。日本の心理学でも利用増 |
| 社会科学全般 | **SocArXiv** | OSF 系。社会学・政治学 |
| 化学 | **ChemRxiv** | ACS 系 |
| 地球・環境科学 | **EarthArXiv** | 地球科学系 |
| 人文学 | **Humanities Commons (CORE)** | MLA 系。書評・短文も可 |

### 日本語論文・国内向け

| 提出先 | 用途 |
|---|---|
| **J-STAGE** | 国内学会誌の電子公開プラットフォーム（学会への投稿経由） |
| **Zenodo** | 日本語論文も登録可。多言語メタデータ対応 |
| 機関リポジトリ | 所属大学のリポジトリ（JAIRO Cloud 等） |

## 選定の判断基準

以下の順序で候補を絞り込む：

1. **分野の慣習**: 自分の分野で「読まれている」サーバーはどこか（査読者・同僚が見る場所）
2. **言語の適合**: 英語以外の論文は Zenodo / OSF / Humanities Commons が無難。SSRN・medRxiv 等は英語が前提
3. **DOI 付与**: 上記主要サーバーはすべて DOI を付与（引用可能性の担保）
4. **ライセンス選択**: CC-BY 4.0 が標準的推奨。翻案を許可したくない場合は CC-BY-ND 等
5. **将来のジャーナル投稿との両立**: 投稿予定ジャーナルのプレプリント方針を **SHERPA/RoMEO** で確認（多くの主要出版社はプレプリント公開を許容）

## 投稿前チェックリスト（品質ゲート）

投稿実行前に、以下をすべて完了させる：

- [ ] [`claim-evidence-gate`](../claim-evidence-gate/SKILL.md) の品質ゲートを PASS している
- [ ] [`citation-traceability-audit`](../citation-traceability-audit/SKILL.md) で引用の1対1対応が確認済み
- [ ] 参考文献リスト（References）が本文引用と完全に一致している
- [ ] `scripts/convert_markdown_to_pdf.py` で最終 PDF を生成し、レイアウト崩れがないか目視確認した
- [ ] アブストラクト・キーワード・著者情報（ORCID 推奨）が最新である
- [ ] ライセンス（CC-BY 等）を明記した
- [ ] 利益相反・研究倫理声明（必要な分野では IRB 承認番号）を記載した

## 複数サーバーへの展開（例: Zenodo + SSRN）

同一論文を複数のサーバーに登録することは一般に可能だが、以下に注意する：

- **バージョン管理**: 各サーバーで同一バージョン（改訂日・版数）を維持し、改訂時はすべて更新する
- **相互リンク**: 各登録ページの関連識別子欄に他方の DOI/URL を記載し、同一成果であることを明示する
- **二重投稿との区別**: プレプリントの複数登録は問題ないが、査読付きジャーナルへの同時二重投稿は倫理規定違反となる
